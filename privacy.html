Privacy policy

Flight Tracker · last updated 18 October 2026

Flight Tracker is a personal tool. It is built and used by one person to keep track of their own family's travel bookings. It is not offered to the public and has no other users.

What it reads

  • Gmail, read-only: booking confirmation emails from airlines, hotels and travel agents in the owner's own mailbox, so that flights, hotels, references and fares can be listed in one place. It cannot send, delete or change email.
  • Google Drive, only files it creates: it saves each booking's confirmation as a PDF into a folder of its own. It cannot see any other file in the Drive.

Where the data goes

The extracted booking details are stored in a private GitHub repository that only the owner can access, and in the owner's own Google Drive. Nothing is sold, shared, used for advertising, or sent to any third party. No analytics or tracking of any kind is used.

This public web page holds no booking data. The app fetches the owner's data in the owner's browser using a key kept on the owner's own device.

Use of Google data

Flight Tracker's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be withdrawn at any time from Google account permissions, after which the app can no longer read mail or write to Drive.
